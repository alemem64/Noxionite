# Social Image Contract

## Source Of Truth

- Runtime OG API: `pages/api/og.tsx`
- OG URL helper: `lib/get-social-image-url.ts`
- Legacy static generator: `scripts/generate-social-images.mjs`
- Legacy Puppeteer renderer: `lib/og-images-manager.ts`,
  `lib/og-images-batch.ts`

## Contract

- Production Open Graph images are generated by `/api/og` using `next/og`.
- Vercel build must not launch Puppeteer or Chromium. Static generation is
  skipped on Vercel unless `GENERATE_STATIC_OG_IMAGES=1` is explicitly set.
- The legacy static generator is local-only by default and may be used for
  debugging or future static export workflows.
- `/api/generate-social-image` is a compatibility redirect to `/api/og`.

## Verification

- `VERCEL=1 npm run postbuild`
- `curl -I 'http://localhost:<port>/api/og?title=Test&description=Hello'`
- Confirm `Content-Type` is `image/png`.
